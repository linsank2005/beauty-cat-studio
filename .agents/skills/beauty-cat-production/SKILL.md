# 画面生产

先读 `README.md`、`docs/IP与风格规范.md` 和 [汗液视频复学与应用](../../../docs/learning-v2/汗液视频复学与应用.md)。当前 Agent 承担美术、对齐、合成和检查，不自动开多个代理。

## 素材

- 采用 `studio/public/ip/cat-sit-neutral.png` 为跨期母版。额外表情只替换脸区，其他像素沿用母版。新姿态以母版作图像编辑参考；保持胖软奶油白身体、黑卷发、六个粉卷发器、粗线条与成年人气质。
- 使用 imagegen 生成/编辑栅格图；真实 alpha PNG，完整爪子/发丝、留出透明边缘。保留提示词、参考路径和输出来源；实际看图并检查 alpha。文字在后期叠加。
- 不分别生成登场阶段。`src/Cat.tsx` 从同一母版的路径/遮罩得到阶段，组件保持固定画布。`exports/templates/` 提供阶段 PNG、透明 WebM、ProRes4444 MOV 和预览。
- 主要人物、道具、场景的绘出按已审分镜分组制作：同一对象定稿 → 对应墨线/路径 → 分区色面 → 必要细节 → 表演状态。中间阶段用同一来源和固定坐标的图层/遮罩，不独立生成多张“同一图”的阶段稿。新姿态定稿仍须以身份母版作编辑参考；另生成的线稿不得未经检查就当作与彩稿已对齐。
- 现有猫 `draw` 仅支持坐姿；复杂背景/其他姿态需在当期制作中补专用路径、色区遮罩或分层 SVG，并检查中间状态。不要把整张彩色 PNG 的淡入/横向擦入称为逐步画完，也不要强套坐姿遮罩。
- 编排角色的态度转折：在对应口播关键词上使用 `reactions`，优先复用平静、惊讶、得意，配合挑眉等局部动作。坐姿和抬爪均支持这三种表情；若素材不适用于当前姿态，须补同姿态脸部编辑并实际检查，不能让表情设置静默失效。切换只替换脸区，不能连带更换发型、身体或手持物。
- 情境道具优先独立素材，放 `studio/public/props/` 或 `public/episodes/<期号>/`。当前通用 SVG 可复用；不要硬把不相干的旧道具塞进新选题。
- 主要道具以母版及用户已确认的 `docs/style-v3/approved/` 场景共同作笔触/配色参考。当前背景与透明道具图集在 `public/props/style-v3/`，提示词与来源在 `docs/style-v3/generation-record.json`，图集坐标在 `docs/style-v3/atlas.json`。在实际构图中检查线条、细节密度、主次、台面遮挡与爪子接触；透明单图好看不等于合成后协调。style-v2 保留供历史样片复现。

## 人物表演

- 按主表使用已选姿态与起始/接触/结果状态。原始 `IP参考/` 是动作意图来源，不代表每张都已整理成可合成素材；按本期需要补，不预先造庞大库。
- 握持、喝、拿取、撑地等动作补真实手爪/物件状态；移动或换脸不能冒充不同身体行为。关键姿态切换在动作结果、切镜或遮挡处组织，避免长溶解叠出双手双头。
- 背身 `walk` 已有程序化步态，脸部固定；正面仅平静表情。当前坐姿/抬爪支持三种脸区表情。超出支持范围时补素材与实现，不能静默忽略设置。
- 录音后分别对齐对象出现、重要细节、动作和反应；留出结果阅读时间。语速较快时合并次要绘出步骤，不统一拉伸所有动作或每次固定绘出 2.4 秒。

## 真实录音到实际时间

1. 环境检查：`./Start-Cat.ps1 -Action doctor`。
2. 原稿已 `approved` 才对齐：`-Action align -Episode <期号> -Audio <真实录音绝对路径>`。
3. 本地 FFmpeg 解码＋faster-whisper small CPU/int8，识别逐词时间后与原稿匹配。原稿和预计时间保留；实际稿另存 `episode.aligned.json`，字幕采用已审原文而非直接照抄 ASR 错字。
4. 检查 `alignment/alignment-report.json`。漏句、改说或低匹配率会停止生成实际稿；核对差异后修正原稿/识别结果，不强行沿用旧句。关键词未匹配的事件标记为句内估计。
5. 播放关键段，核对停顿、语义动作和包袱。ASR 逐词时刻及词内均分不是音素级强制对齐；不得声称自动对齐等于逐帧人工听审。

## 合成与交付

- `-Action review -Episode <期号> -Actual` 查看实际时间关键画面。
- `-Action check -Episode <期号> -Actual` 后用 `-Action render -Episode <期号> -Actual`，输出到 `exports/<期号>/`。`-Silent` 导出纯画面；`-Clean` 移除烧录字幕但仍交独立 SRT。
- 更新了图或时间必须重渲染。现有输出默认防覆盖，授权修订用 `-Overwrite`。保留原稿和必要复现材料。
- 先检查线稿/半上色/细节/动作结果等关键变化，再播放导出视频；核对姿态是否对应口播、接触是否成立、最后揭示是否跳变。用 ffprobe 检查时长/分辨率/帧率/音频流，FFmpeg 完整解码检查。alpha 模板应实测透明通道。静态帧不证明节奏或声音同步。
- 交付 MP4、独立 SRT、主表快照和可编辑源文件/实际用到的素材；明确无声/预计/实际状态及未确认处。
- 配音、音乐、音效由用户负责；可把用户干声合入成片用于后续剪辑。内部参考音频测试不得进入原创样片。
