# 画面编排

读 `docs/IP与风格规范.md`、`docs/learning-v2/参考机制复学.md`、[汗液视频复学与应用](../../../docs/learning-v2/汗液视频复学与应用.md) 和当前 `episode.json`。每期主表是唯一时间线，不另写一份独立台词。

## 把一句话变成视觉事件

1. 给场景 `S01…`；一个构图可持续十几秒，只要内部信息在推进。场景覆盖完整时长，口播单元各归属一个场景。
2. 场景写起始构图 `initialState`，再按说话重点写事件 `E01…`：发生什么变化 `action`、为什么需要 `meaning`、与口播的关系 `method`、引用的 `narrationId` 和预计时刻 `at`。
3. 优先约 2—3 秒出现新信息；不强制切图。先设计完整构图，再规划主要对象的可识别线稿/关系 → 分区色面 → 必要细节 → 动作结果/反应。线、色、细节可按对象穿插；不能只在开头画猫，其他画面全用完整静图淡入。一个物件出现只是信息的一步。
4. 直接画面用于交代处境与解释；隐喻用于让抽象关系可见；反差由台词与事实画面共同形成；角色反应给笑点一个可读停留；回扣重新使用前面的物件或处境。
5. 禁止只做关键词配图、静图推拉、无意义飘动或不断重复猫猫登场。没有动画思路时，先判断本段究竟需要解释、对比还是反应。
6. 猫、道具、长文字、线条各为独立图层。主表 `layers` 用 `showAt` 引用事件；状态变化用 `reactions`，移动用 `motion`。复杂手臂、连接关系和姿态改变需实际新状态素材。
7. 事件尽量写 `anchor` 为原稿中的独特词组，供录音后按实际关键词对齐。没有关键词的视觉停留仍可估计，但须在录音后复核；不要用统一拉伸替代逐句重新编排。
8. 构图同时确定美术关系：按用户已确认的 3.0 成人日常漫画范例，使用明确墨线、有限色面、前景遮挡与中近景变化。道具必须参与讲述，优先空间关系与冷面反应；不把温柔纸条、浅粉卡片或对错符号当作默认画面。简单解释场景允许留白，不强制完整房间。

## 实现范围

现有通用图层：`cat / image / text / path / shape`；出现方式 `draw / pop / wipe / fade / none`。`draw` 猫模板仅用于坐姿母版；其他姿态没有通用分区绘出。当前 `view` 支持坐姿、正面、抬爪、背身步态（`sit/front/groom/walk`），用 `studio/public/ip/` 真素材。路径和说明图使用独立 SVG；新姿态/道具按镜头需要补，不预建庞大素材库。完整图片 `wipe` 只是擦入；非坐姿与复杂场景的线稿/填色需实际分层或对应遮罩。

旧 `scene.art` 的五种纸面构图与 `shape: note` 保留用于历史样片，新作品以 `docs/style-v3/approved/` 为画风基准。STYLE12 展示独立背景与透明道具图集；`sourceRect` 可引用图集局部，`clipPath` 用于遮挡，`motionEasing: smooth` 控制道具移动。新题材另画对应场景，不硬套梳妆道具。

## 分镜阶段确定阶段与表演

- 先按口播动词与情绪选择姿态，查看上述复学文档的自有 IP 动作目录。标清已可用素材与需要母版编辑的新姿态；不要因为现成模板有限就全程用抬爪。
- 主要行为写清起始状态 → 动作/手爪与道具接触 → 结果 → 表情反应，并分别安排关键词锚点与预计时间。持续同一行为可保持姿态，不设动作数量配额。
- 主要对象的线条、色区、细节与表演分别写入现有 `beats.action/meaning`，引用相应图层。简短镜头可合并上色步骤；重要动作与反应不能被绘出过程挤掉。
- 生活场景、局部解释、隐喻和反应近景按内容交替；同场景中不把猫反复从头画出凑变化。长时间复用姿态时检查它是否仍对应正在说的行为。
- 姿态改变需要真实身体/接触状态。整体平移、旋转、换脸不能替代喝、拿、撑地等动作；切换考虑重心、爪子、接地影和遮挡，避免无理由跳变。

## 审阅包

1. `Start-Cat.ps1 -Action check -Episode <期号>` 检查覆盖、引用、顺序和缺图。
2. `-Action review` 生成完整口播、六列主表、预计 SRT/字幕 JSON、各场景代表状态的实际画面预览，位于该期 `review/`。此时 `status=draft` 可以生成审阅画面，禁止当正式成片交付。
3. 对代表性构建段落补线稿、部分填色、细节完成与表演结果的实际状态图；主要行为变化展示对应姿态，不只交每场景的一张完成图。复杂段落按需要补前后截图或短预览。核对焦点、遮挡、接触、猫的辨识度与变化作用；未制作的阶段须标为计划。
4. 一次性让用户审阅完整口播和对应画面；得到确认才改为 `approved`。改说或改图同时回写主表，影响到的录音也重新处理。
