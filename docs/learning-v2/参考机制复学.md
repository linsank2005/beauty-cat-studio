## 1. 主角确实能分阶段补全

游隼 `BV1UFge6qEty` **96—103 秒**，4fps 密集取样，边界分辨率约 0.25 秒：[前半](FALCON_DRAW-01.jpg)、[后半](FALCON_DRAW-02.jpg)。

约 96.5 秒开始鸟身与头眼轮廓，随后爪线；97.25 秒出现眼部颜色，97.75—98.5 秒依次补头部/身体、翅膀、羽纹和脚色；98.75 秒加动势线，100.5 秒背景加大字，102 秒换举牌姿态。**绘出、标签、姿态是不同的事件**，角色完整后仍可推进构图。

粉猫实现：同一母版的真实轮廓 SVG 路径描边，再依序揭示五官/身体、黑发、粉卷发器。六阶段 PNG 与透明动画来自一个组件；惊讶/得意为脸区状态，正面/抬爪另做关键姿态。没有把每个阶段重新生成，避免身份和位置漂移。模板末段停留后可以继续作为完整猫使用。

## 2. 一张底图可以承载多次解释

肚脐 `BV19YohBnECC` **37—44.5 秒**，4fps：[前半](NAVEL-01.jpg)、[后半](NAVEL-02.jpg)。

37.25 秒左右有结构轮廓，37.5—38 秒逐渐补组织/内部路径；38.25—38.5 秒加入另一组通路；随后箭头和“脐静脉”“脐动脉”等标签。构图相对稳定，但结构、关系、命名依次可读。

粉猫实现：一个场景写 `initialState`，内部每个信息点写独立事件与图层。相同底图可以用十几秒，需明确每次新增/改变的内容及作用。现有 `path / image / text` 可把线、道具、箭头和标签分开安排；需要复杂结构时按主题补实际 SVG 或状态图。

## 3. 隐喻需要逐步建立，而不是给抽象词配一张图

睡觉翻身 `BV1sLPWzNEmy` **133.5—138.5 秒**，4fps：[密集序列](SLEEP-01.jpg)。

134 秒附近先画脑角色轮廓，再补面部、身体/手臂；之后逐次加入食物、核桃、盘子、收音机等内容。角色和环境逐步组成一个能读懂的拟人情境，新的物件承担新的信息。

粉猫样片 S02：一句“脑子里开了八个项目”，任务卡按不同事件不断加入，猫最后惊讶。抽象的“总想全改”通过越来越拥挤的任务变得可见；台词无需把八张卡逐一念完。

## 4. 状态切换本身可以说明关系

汗疱疹 `BV1Yptj6zEEG` **198.5—204.5 秒**，4fps：[前半](SKIN-01.jpg)、[后半](SKIN-02.jpg)。

两个拟人角色连接/拉手，约 202 秒连接断开、距离拉开，随后表情反应变化。不是仅靠人物平移表达，而是**关系改变＋反应**共同说明。

粉猫实现：每次需要真正改变手臂、物件接触或连接关系，提供对应新状态素材；不能靠缩放静图假装已经完成动作。首批演示抬爪姿态、梳子沿发型移动；这是关键姿态加道具动画，不是完整手臂逐帧绑定。

## 5. 台词与画面可以用反差合作

蚊子 `BV1mkg36zEfX` **15—19.5 秒**，4fps：[密集序列](MOSQUITO-01.jpg)。

自信的蚊子与有明显受伤表现的另一角色同框，随后蚊子表情/姿态变换，背景处境保持；说话角色的态度与可见后果形成反差。这里根据画面、字幕分析，未据截图单独推断配音语气。

游隼开场 **0—13 秒**，2fps：[前半](FALCON_OPEN-01.jpg)、[后半](FALCON_OPEN-02.jpg)。角色先围绕窝对话，画面随后切近窝、蛋掉落和震惊反应，让之前“可以用”的说法被可见结果推翻。

粉猫样片 S03：台词“洗手台，不是施工现场”，洗手台与施工牌形成纠偏，红色叉号作为反应结果。笑点由处境、道具与台词共同成立，照搬原作者的角色或桥段没有必要。

## 6. 科普部分仍需要直接画面与比较

游隼 **74.5—97.5 秒**，2fps：[第一段](FALCON_COMPARE-01.jpg)、[第二段](FALCON_COMPARE-02.jpg)、[第三段](FALCON_COMPARE-03.jpg)。

观察到插画与真实鸟照片、眼部/鼻部标签、猫头鹰和翅膀轮廓比较、眉部变化等。拟人角色负责带入与反应，直接示意与对照承担解释，不能把所有机制都改写成笑点或隐喻。

粉猫后续规则：关键事实和因果优先用直接结构/关系图；抽象压力、体验和观念可用隐喻；需要分辨差异时用并排比较或局部强调。事实来源单独查证，不使用参考字幕替代一手资料。

游隼总长约 453 秒，按每 6 秒一帧抽样，共 76 帧，另读配套 AI 字幕：[1](FALCON_OVERVIEW-01.jpg) / [2](FALCON_OVERVIEW-02.jpg) / [3](FALCON_OVERVIEW-03.jpg) / [4](FALCON_OVERVIEW-04.jpg)。整体呈现问题对白、现实后果、身体结构与比较、速度/行动表现、角色反应和后段其他内容。概览只定位段落窗口，不用于确定每个动画边界。

## 固化为三条生产规则

1. **口播与画面一起写。** 可录单元编号稳定，每个视觉事件说明对应台词、变化、作用和关系类型；一条口播可含多个事件。
2. **变化增加信息。** 优先逐步补全、物件累积、标签/关系变化和反应；约两三秒推进一次，不靠重复登场或无意义晃动凑数量。
3. **角色身份固定，时间随真实录音重排。** 稳定母版与必要状态独立制作；原计划保留，实际句段/关键词另写，听看复核关键时刻。
