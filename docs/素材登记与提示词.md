## 制作提示词要点与后续复用模板

以下归档制作约束与可复用提示词，不冒充每次工具调用的逐字日志。后续生成应记录本次实际提示词及工具返回源路径，并更新对应素材登记。

**身份整理 / 新姿态共用：**

> 编辑参考中的同一只猫，保留奶油白胖软身体、黑色卷发、六个粉色卷发器、小鼻口、粗黑手绘轮廓、原有插画质感与慵懒成年人气质。不要改成幼猫、三维渲染或写实毛发。完整保留爪子和外侧卷发，不裁切，方形画布周围留透明空间；真实 alpha 透明背景，无文字、水印、额外角色和新装饰。

**母版留边修正：**

> 仅调整原猫在方形画布中的比例和留边，不改变猫的设计、姿态、表情或发型。让角色约占画布宽度 82%、高度 84%，四周有足够透明边缘，完整展示头发与爪子。

**表情编辑：**

> 使用定稿坐姿母版。仅编辑奶油白脸区的眼、眉和口型；身体、头发、卷发器、爪子、画布大小和角色位置沿用参考。惊讶版本：睁大眼、小 O 口；得意版本：半眯眼、嘴角微弯，保持原猫的成年与嘴硬气质。透明背景。

图像模型仍可能轻微改变脸外像素，所以生产组件不直接切整张表情图，而用脸区裁剪覆盖母版。八张阶段/表情 PNG 也是通过组件导出；脸外一致性有实际像素检查。

**正面 / 抬爪：**

> 以定稿坐姿母版为身份参考，保持同样卷发与六个粉卷发器、胖软体态、奶油色、粗线条和插画质感，完整留边。正面版本面朝观众；抬爪版本把猫的左前爪（观众视角右侧）抬到脸和头发附近，另一只前爪支撑身体。抬爪图本身不画梳子，梳子由独立图层叠加。

## 动画与道具

**新一期的画面编排提示词：**

> 按这一段口播的主要行为与情绪转折选猫姿态，引用自有 IP 动作参考并标注素材是否已可用。先设计完整构图，再写主要对象的线稿/关系、分区填色、必要细节，以及画完后的动作结果和表情反应；每个事件有台词锚点、预计时间和作用。线、色、细节可按对象穿插，简短镜头可合并次要步骤。不要全程同一抬爪姿态，也不要只有开头绘出。画风采用已确认成人日常漫画，保持有力度墨线、有限色面、空间与遮挡；变化以内容需要为准。

**构建素材与接触动作提示词：**

> 以固定猫母版为身份参考，以指定自有 IP 图片为动作意图参考，采用已确认 3.0 场景的笔触和色面。制作本镜头所需的【姿态/起始/接触/结果】，保持母版胖软身体和六个粉色卷发器；手爪与【道具】的握持、接触和遮挡必须成立。使用固定画布和清晰锚点，保留透明边缘。该姿态定稿后再从同一来源拆线、色、细节及遮罩，不能分别生成不同阶段。道具、文字、接地影按互动需要独立组织。不要把原参考的背景、文案、不同体型一并复制。

上述是生产约束模板，不是新的生成记录。本次没有生成素材。动作目录、具体时间证据及当前组件能力见 [汗液视频复学与应用](learning-v2/汗液视频复学与应用.md)。现有坐姿绘出可直接复用；其他姿态与复杂背景的分区绘出须按期补专用图层/遮罩，不把 PNG 擦入视为已实现。

- `studio/src/Cat.tsx`、`cat-geometry.json`：母版轮廓描边、颜色区域揭示、固定脸区覆盖。`scripts/trace_cat.py` 只分析 alpha 几何生成路径，不编辑源 PNG。
- `studio/public/props/mirror.svg`、`comb.svg`、`sink.svg`、`construction.svg`、`door.svg`：本项目绘制的独立简化矢量道具，可改色、尺寸和出现时间。
- `exports/templates/`：同一组件导出的阶段 PNG、透明 VP9 WebM、ProRes4444 MOV、预览和 IP 总览；不是独立生成的阶段图片。
- 文字、叉号、任务卡和箭头由主表与原生图层生成，不写入猫图。

素材尺寸、alpha 检查、导出表达式和 SHA256 在 `docs/verification/media-verification.json` 与交付包清单中。五条参考视频的截图与少量声音仅用于内部复学/技术测试，不作为新作品的画面或配音素材。
