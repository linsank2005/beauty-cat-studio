# 出门前，脑子里开了八个项目 · 2K 口播样片

成片为 16:9、2560×1440、30fps，24.77 秒，带用户口播与字幕。使用已确认的成人日常漫画画风，同一奶油白粉卷发器猫母版。

## 这次调整

- 结尾修订 3.3：参考自有 `cat_ip_09.png` 的回头姿态，替换最后约 2.2 秒的静止站立。两脚交替抬起、左右摆胯，沿地面透视走向门洞并被门扇逐步遮住。角色用同一背身 PNG 做连续局部变形，避免分块腿部接缝；没有新增配乐或脚步音效。`WalkingCat.tsx` 和主表 `walk` 参数可复用。
- 表情修订 3.2：在“脑子 / 人生”露出惊讶，在“穿搭”短暂得意，“等一下”恢复冷静并挑眉，“整理好”和“只是终于肯出门”用小笑。抬爪表情以原姿态及已有坐姿表情编辑，只覆盖面部内区；发型、身体、手爪及道具沿用原画。背景、口播、字幕、实际事件时间保持上一版；上一版 MP4 与主表在 `exports/DEMO_V3_2K/previous-v3.1/`。
- 浴室内持续使用同一构图：逐步绘出 → 蓝图与施工道具累积 → 挑眉叫停 → 道具退出 → 拿起梳子。先收完施工再进入梳头，避免原 12 秒版约 8 秒的突切。
- “头发、黑眼圈、穿搭、人生重做”各有对应道具；梳子绕爪子的接触点转动，动作跟随“头发 / 整理 / 好”。
- “看，我没变成另一只猫”延续猫的位置，8 帧短转场到墨蓝门口，缓慢退开；句尾留出停顿。
- 用户的 `1小猫Luo.mp3` → `2小猫Luo.mp3` 原速拼接，结尾加 0.65 秒静音。没有配乐、音效或变速。导出后从 0 秒直接合入原始音轨，避免渲染器混音带来的编码延迟与电平改变。

## 主表与时间

`episode.json` 保留原 32 秒预计分段；`episode.aligned.json` 是实际录音对应的编排。N01—N07沿用原稿，N08句尾按录音记作“啦”；原 `episodes/DEMO/` 不修改。两段分别识别以修正拼接后识别把停顿计入词首的问题；时间依据为词时刻及停顿复核，不是音素强制对齐。

素材提示词、编辑参考和图集坐标在 `generation-record.json`。原始音频校验、完整识别与调整依据在 `alignment/`。正式素材在 `studio/public/ip/`、`studio/public/props/style-v3/`，不独立生成猫的绘出阶段。

## 复现

在项目根目录运行：

```powershell
./Start-Cat.ps1 -Action check -Episode DEMO_V3_2K -Actual
./Start-Cat.ps1 -Action review -Episode DEMO_V3_2K -Actual -Overwrite
./Start-Cat.ps1 -Action render -Episode DEMO_V3_2K -Actual -Overwrite
```

首次重新识别时先执行 `-Action align`，再运行本期 `alignment/refine_timing.py` 恢复已校正的事件时间；使用新录音时须重新核对，不能套用本次固定时间。`-Clean` 另外导出无烧录字幕版本。输出目录为 `exports/DEMO_V3_2K/`，包括 MP4、独立 SRT 和实际主表快照；Remotion 中选择 `DemoVoice2K`。

完整解码、音视频流、源声音相关性与播放检查结果见交付目录 `verification.json`；必要关键帧保留在 `inspection/`。
